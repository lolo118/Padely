# Ranks

The rank ladder: one padel ball, faster at every level. Nine SVG marks on a 24px grid, used by CategorySelect, next to player names, in the ranking and on the profile.

- `8va.svg` — the ball still in its wrapper: a dashed ring.
- `7ma.svg` — the ball.
- `6ta.svg` — one speed line.
- `5ta.svg` — two speed lines.
- `4ta.svg` — three speed lines.
- `3era.svg` — the comet tail.
- `2da.svg` — the bolt cut into the ball.
- `1era.svg` — the star cut into the ball.
- `libre.svg` — the golden ball inside its ring.

Rules

- Inks are fixed inside the files so they read on both themes: `lime` (#84cc16) for the ball and its motion, `night` (#0b1220) for the seam, bolt and star, the gold ramp (`gold-light` #f6dd8d, `gold` #d9a927, `gold-deep` #8b6514) for Libre. Do not recolour.
- Sizes: 20px inline with text, 24px in lists and selects, 40px on a profile. Never below 16px: the speed lines merge.
- Always with the level name beside it ("6ta"); the mark alone is not a label.
- "Suma N" tournament categories are not ranks: they use the two-balls-plus mark drawn by CategorySelect, not a file here.
